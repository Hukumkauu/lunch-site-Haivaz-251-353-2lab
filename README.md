# Вкусный обед

Сайт компании по доставке бизнес-ланчей. Учебный проект по дисциплине «Основы веб-технологий».

**Автор:** Хайваз Никита, группа 251-353, Московский Политех

**Сайт:** https://hukumkauu.github.io/lunch-site-Haivaz-251-353-2lab/

## Страницы

- `index.html` - главная страница: о компании, преимущества, популярные блюда, контакты
- `lunch.html` - страница «Собрать ланч»: комбо, меню с фильтрами, панель перехода к оформлению
- `order.html` - страница «Оформить заказ»: состав заказа и форма отправки на сервер

## Структура проекта

```
├── index.html          главная страница
├── lunch.html          страница «Собрать ланч»
├── order.html          страница «Оформить заказ»
├── css/
│   ├── style.css       общие стили сайта
│   └── lunch.css       стили страницы «Собрать ланч»
├── js/
│   ├── dishes.js       загрузка блюд с сервера (API)
│   ├── storage.js      сохранение выбранных блюд в localStorage
│   ├── display.js      вывод карточек блюд на страницу
│   ├── filter.js       фильтры блюд по типу
│   ├── order.js        выбор блюд и панель оформления на странице «Собрать ланч»
│   ├── check.js        проверка состава ланча и уведомления
│   └── checkout.js     страница «Оформить заказ» и отправка заказа на сервер
└── images/
    ├── lunch.jpg       картинка на главной
    └── icons/          иконки для блока комбо
```
